# ESCP AI website — project notes

Bilingual (EN/FR) site for ESCP AI, the inter-campus student AI society of ESCP Business School.
Live on Vercel, auto-deploys from `main`. Repo: `ishaanverma1857-gif/Escp-ai`.

@AGENTS.md

## Workflow the owner expects
- Work on the `polish` branch. When the owner says "make it live", fast-forward `main` to `polish` and push.
- Build (`npm run build`), type-check (`npx tsc --noEmit`) and lint (`npm run lint`) before pushing.
- Check visually with Playwright screenshots (Chromium at `/opt/pw-browsers/chromium`) at desktop 1440 and mobile 390.
- The session network blocks most image hosts (Wikimedia, Unsplash, escp.eu); the owner uploads photos instead.

## Stack
Next.js 16 App Router (Cache Components on, `proxy.ts` for locale redirect), Tailwind CSS 4, Motion, Lenis smooth scroll,
Montserrat (display) + Atkinson Hyperlegible Next (body). Read `node_modules/next/dist/docs/` before changing Next APIs.

## Where things live
- `content/en.ts`, `content/fr.ts` — all copy (same shape). `content/site.ts` — links, team, campuses, events, products, impact.
- `app/[lang]/…` — pages: home, team, partners, events (+ `[slug]`), services, join, shop, login, `campuses/[campus]`.
- `components/brand.tsx` — "ESCP | AI" wordmark and woven orbit symbol (`Knot`).
- `components/fx.tsx` — FlowLines (pre-rendered to an image for performance; never animate canvases per frame),
  DottedArc, Countdown, ScrollText, VelocityMarquee, Magnetic, Spotlight, Tilt, PointerParallax, ScrollKnot, SmoothScroll.
- `components/motion.tsx` — Reveal/Stagger/MaskedLines/FadeIn/CountUp; `isIntro`/`entryDelay` timing.
- `components/CampusNetwork.tsx` + `components/europe-map.ts` (generated by `scripts/generate-europe-map.mjs`, Natural Earth).
- `app/[lang]/template.tsx` — intro curtain, shown only on a fresh load/reload of the homepage.
- `public/team/*.webp` headshots; `public/campuses/<city>/{campus,1,2,3}.webp`. When replacing an image, use a NEW filename
  (image caches key on URL).
