# ESCP AI website — project notes

Multilingual (EN/FR/IT/ES/DE) site for ESCP AI, the inter-campus student AI society of ESCP Business School.
Live on Vercel, auto-deploys from `main`. Repo: `ishaanverma1857-gif/Escp-ai`.

@AGENTS.md

## Workflow the owner expects
- Work on the `polish` branch. When the owner says "make it live", fast-forward `main` to `polish` and push.
- Build (`npm run build`), type-check (`npx tsc --noEmit`) and lint (`npm run lint`) before pushing.
- Check visually with Playwright screenshots (Chromium at `/opt/pw-browsers/chromium`) at desktop 1440 and mobile 390.
- The session network blocks most image hosts (Wikimedia, Unsplash, escp.eu); the owner uploads photos instead.

## Stack
Next.js 16 App Router (Cache Components on, `proxy.ts` for locale redirect), Tailwind CSS 4, Motion, Lenis smooth scroll,
Montserrat (display) + Atkinson Hyperlegible Next (body). Read `node_modules/next/dist/docs/` before changing Next APIs.

## Where things live
- `content/{en,fr,it,es,de}.ts` — all copy (same shape, typed `Dictionary`). `lib/locales.ts` — language registry (client-safe). `content/site.ts` — links, team, campuses, events, products, impact.
- `app/[lang]/…` — pages: home, team, partners, events (+ `[slug]`), services, join, shop, login, `campuses/[campus]`,
  `built-by` (the website team "Artificially Incompetent"; photos/videos go in `public/builders/`, set in `builders` in `content/site.ts`).
- `components/brand.tsx` — "ESCP | AI" wordmark and woven orbit symbol (`Knot`).
- `components/fx.tsx` — FlowLines (pre-rendered to an image for performance; never animate canvases per frame),
  DottedArc, Countdown, ScrollText, VelocityMarquee, Magnetic, Spotlight, Tilt, PointerParallax, ScrollKnot, SmoothScroll.
- `components/motion.tsx` — Reveal/Stagger/MaskedLines/FadeIn/CountUp; `isIntro`/`entryDelay` timing.
- `components/CampusNetwork.tsx` + `components/europe-map.ts` (generated by `scripts/generate-europe-map.mjs`, Natural Earth).
- `app/[lang]/template.tsx` — intro curtain, shown only on a fresh load/reload of the homepage.
- `public/team/*.webp` headshots; `public/campuses/<city>/{campus,1,2,3}.webp`. When replacing an image, use a NEW filename
  (image caches key on URL).

## Dashboard prototype (`app/[lang]/dashboard/…`, English only)
- Postgres via Neon (Vercel Marketplace, env `DATABASE_URL`), `pg` driver in `lib/db.ts`; tables are created and members/tasks
  seeded on first query. Events + registrations are real data; members + tasks are fictional sample data (`lib/sample-data.ts`).
- Roles from Clerk public metadata `{ "member": true, "role": "superadmin|branchadmin|divisionlead|member", "campus", "division" }`;
  permissions in `lib/viewer.ts`, re-checked in every server action (`lib/actions/*`).
- Public events = content events + published DB events (`lib/event-store.ts`, `"use cache"` + `cacheTag("events")`, `updateTag` on publish).
- Event recaps (English summary, takeaways, links, transcript made with AI from the recording): `recaps` table, edited per event
  in the dashboard (`components/dashboard/RecapForm.tsx`, includes the AI prompt), shown on the event page (`components/EventRecap.tsx`)
  and listed on /events (`lib/recaps.ts`, `cacheTag("recaps")`).
- Recaps written into the site, in all 5 languages with a switcher: `content/recaps/<slug>/{en,fr,it,es,de}.ts` (Markdown strings),
  registered in `content/recaps/index.ts`; they take precedence over dashboard recaps (`components/StaticEventRecap.tsx`, `lib/markdown.tsx`).
- Local testing: start Postgres on :5433 and put `DATABASE_URL` + `PROTOTYPE_DEV_ROLE=superadmin` in `.env.local`
  (the stand-in user only works with no Clerk keys and outside Vercel).
